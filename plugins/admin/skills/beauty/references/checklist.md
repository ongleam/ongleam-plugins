# 완료 확인

요청 범위 밖의 항목은 해당 없음으로 표시한다.

- [ ] 현재 MCP 계약·신원·조직·프로젝트를 확인했다.
- [ ] 현재 키워드·조건·전체 수집 연결을 반영하고 URL을 키워드로 섞지 않았다.
- [ ] 필요한 페이지/사전을 끝까지 읽었으며 기간·설정·연결·전체/플랫폼 집계가 일치한다. 미완료는 partial이다.
- [ ] 원본·부정·공개 가능·매칭 레코드·중복 제거 게시물 수를 구분했다. 누락·실패를 0으로 바꾸지 않았다.
- [ ] 근거는 정확한 원문이며 모든 매칭 이름·강조가 카드에 보존된다. 후보를 상품 불만으로 확정하지 않았다.
- [ ] SSOT 스키마·builder로 저장하고 read-back했다. 비밀값·임시 원문·author ID를 공개하지 않았다.
- [ ] UI 변경은 localhost에서 실제 검색·필터·정렬·모바일 표시를 확인했다.
- [ ] 게시했다면 같은 소스의 새 Next.js 빌드·AWS 배포 성공과 운영 화면을 대조했다.
- [ ] 예약은 요청된 경우에만 기존 일정과 조정하고 실제 실행 완료를 확인했다.
- [ ] 조회·저장·배포·예약 결과와 미검증 사항을 구분해 보고했다.
